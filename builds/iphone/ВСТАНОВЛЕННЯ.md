# Встановлення РозкладкаВ на iPhone (без Mac, через Sideloadly)

Файл `РозкладкаВ.ipa` зібраний автоматично (GitHub Actions, безкоштовний
macOS-раннер) і лежить поруч, а також на `C:\Users\Admin\Desktop\rozkladka_v\
builds\iphone\РозкладкаВ.ipa`. Він не підписаний — підпис і встановлення
робиш сам, безкоштовно, прямо з Windows.

## Крок 1. Встановити Sideloadly

Скачай і встанови з офіційного сайту: **sideloadly.io** (кнопка "Download"
для Windows). Це не App Store і не хак — офіційний легальний спосіб
встановити застосунок на власний iPhone без Mac, тим самим механізмом, що
й Xcode "Personal Team".

## Крок 2. Підключити телефон

USB-кабелем до цього ж комп'ютера (уже підключений). Якщо з'явиться
запит "Довіряти цьому комп'ютеру?" на телефоні — натисни "Довіряти" і
введи код розблокування.

## Крок 3. Sideloadly

1. Відкрий Sideloadly — телефон має з'явитись у списку пристроїв зверху.
2. Перетягни файл `РозкладкаВ.ipa` у вікно Sideloadly (або кнопка вибору
   файлу).
3. Введи свій Apple ID (той самий, що на телефоні) і пароль — Sideloadly
   попросить один раз, щоб підписати застосунок. Якщо ввімкнена
   двофакторна перевірка — підтвердь код на телефоні, коли попросить.
4. Натисни "Start" — Sideloadly підпише і встановить застосунок
   автоматично. Займає 1-3 хвилини.

## Крок 4. Увімкнути Режим розробника (iOS 16+)

Без цього кроку застосунок не відкриється, навіть після довіри
розробнику нижче — окрема вимога Apple з iOS 16, не залежить від способу
встановлення.

1. **Налаштування → Конфіденційність і безпека** → прокрути вниз до
   **Режим розробника** → увімкни перемикач.
   (Якщо пункту нема в списку — він з'являється лише **після** першої
   спроби встановити застосунок через Sideloadly, тобто після Кроку 3.
   Якщо ще нема — повтори Крок 3, тоді перевір знову.)
2. Телефон попросить **перезавантажитись** — погодься.
3. Після перезавантаження, коли розблокуєш телефон, спливе вікно
   **"Увімкнути режим розробника?"** → **Увімкнути** → введи код
   розблокування.

## Крок 5. Довірити застосунок на телефоні

Іконка вже на головному екрані, але запуск одразу покаже помилку
"Ненадійний розробник" — це нормально для будь-якого застосунку поза App
Store. Виправляється один раз:

**Налаштування → Основні → VPN та управління пристроєм** → знайти свій
Apple ID у списку → **Довіряти "[твій Apple ID]"** → підтвердити.

Тепер застосунок відкривається звичайно.

---

**Важливо:** підпис безкоштовного Apple ID діє **7 днів**. Через тиждень
застосунок перестане відкриватись — повторити Крок 3 (Sideloadly вже
запам'ятає файл і Apple ID, займе секунди; Кроки 4-5 повторювати не
треба, вони лишаються увімкненими). Для довшого терміну без
перепідписання потрібен платний Apple Developer Program (99$/рік) — не
обов'язково для тестування.

---

## Якщо Sideloadly пише "No device detected"

Найімовірніше — на Windows нема драйверів Apple:

1. Встанови **iTunes з офіційного сайту Apple** (`apple.com/itunes`,
   саме .exe-інсталятор із сайту, не версію з Microsoft Store).
2. **Перезавантаж комп'ютер** — драйвери реєструються тільки після
   перезапуску.
3. Відключи й підключи телефон заново, розблокуй його — має спливти
   "Довіряти цьому комп'ютеру?" → Довіряти → код розблокування.
4. Відкрий Sideloadly знову.

Якщо все ще не бачить — спробуй інший USB-кабель (частина кабелів лише
заряджають, без передачі даних) або інший USB-порт.
