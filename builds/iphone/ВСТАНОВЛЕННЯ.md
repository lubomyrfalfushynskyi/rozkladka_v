# Встановлення РозкладкаВ на iPhone (без Mac, через Sideloadly)

Файл `РозкладкаВ.ipa` зібраний автоматично (GitHub Actions, безкоштовний
macOS-раннер) і лежить поруч, а також на `C:\Users\Admin\Desktop\rozkladka_v\
builds\iphone\РозкладкаВ.ipa`. Він не підписаний — підпис і встановлення
робиш сам, безкоштовно, прямо з Windows.

## Крок 1. Встановити Sideloadly

Скачай і встанови з офіційного сайту: **sideloadly.io** (кнопка "Download"
для Windows). Це не App Store і не хак — офіційний легальний спосіб
встановити застосунок на власний iPhone без Mac, тим самим механізмом, що
й Xcode "Personal Team".

## Крок 2. Підключити телефон

USB-кабелем до цього ж комп'ютера (уже підключений). Якщо з'явиться
запит "Довіряти цьому комп'ютеру?" на телефоні — натисни "Довіряти" і
введи код розблокування.

## Крок 3. Sideloadly

1. Відкрий Sideloadly — телефон має з'явитись у списку пристроїв зверху.
2. Перетягни файл `РозкладкаВ.ipa` у вікно Sideloadly (або кнопка вибору
   файлу).
3. Введи свій Apple ID (той самий, що на телефоні) і пароль — Sideloadly
   попросить один раз, щоб підписати застосунок. Якщо ввімкнена
   двофакторна перевірка — підтвердь код на телефоні, коли попросить.
4. Натисни "Start" — Sideloadly підпише і встановить застосунок
   автоматично. Займає 1-3 хвилини.

## Крок 4. Довірити застосунок на телефоні

Після встановлення іконка з'явиться на головному екрані, але запуск одразу
покаже помилку "Ненадійний розробник" — це нормально для будь-якого
застосунку поза App Store. Виправляється один раз:

**Налаштування → Основні → VPN та управління пристроєм** → знайти свій
Apple ID у списку → **Довіряти "[твій Apple ID]"** → підтвердити.

Тепер застосунок відкривається звичайно.

---

**Важливо:** підпис безкоштовного Apple ID діє **7 днів**. Через тиждень
застосунок перестане відкриватись — повторити кроки 3-4 (Sideloadly вже
запам'ятає файл і Apple ID, займе секунди). Для довшого терміну без
перепідписання потрібен платний Apple Developer Program (99$/рік) — не
обов'язково для тестування.
