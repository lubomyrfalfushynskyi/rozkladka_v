# iPhone-версія — статус

`.ipa` тут ще нема (готовий APK збирається сам, готовий IPA — ще ні), але
з версії 2.10 збірка автоматизована: `.github/workflows/ios-build.yml`
на кожен push у `main` компілює непідписаний `Runner.ipa` на безкоштовному
GitHub Actions macOS-раннері (репозиторій публічний — macOS-хвилини без
ліміту й без оплати) і викладає його як build-артефакт на вкладці Actions
GitHub-репозиторію.

Підпис і встановлення на реальний iPhone — окремий крок через **Sideloadly**
(`sideloadly.io`, безкоштовно, працює з Windows) з безкоштовним Apple ID,
без Mac. Діє 7 днів, потім потрібне повторне встановлення тим самим
способом. Повна інструкція — `ІНСТРУКЦІЯ.md`, розділ 15.

Живий iOS Simulator (для клацання руками, не для встановлення на пристрій)
GitHub Actions не дає — для цього досі потрібен Mac (свій/орендований).
