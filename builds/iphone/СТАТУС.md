# iPhone-версія — статус

Ще не зібрана. Код застосунку кросплатформний (Flutter) і технічно
готовий до збірки під iOS, але сама збірка `.ipa`-файлу вимагає Xcode, який
працює лише на macOS — фізичного чи орендованого Mac поки немає.

Коли з'явиться доступ до Mac (свій, орендований у хмарі — MacinCloud/
MacStadium, чи через GitHub Actions macOS-раннер) — сюди з'явиться готовий
`.ipa` і інструкція встановлення поруч, за тим самим принципом, що й
`builds/android/`.

Детальніше про варіанти доступу до Mac — в `ІНСТРУКЦІЯ.md`, розділ про
iOS-розробку.
