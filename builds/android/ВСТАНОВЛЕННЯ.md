# Встановлення РозкладкаВ на Android

## Крок 1. Перенести файл на телефон

Скопіюй файл `РозкладкаВ.apk` на телефон будь-яким способом:
- через USB-кабель,
- через Telegram (собі в "Збережені повідомлення"),
- через Google Диск / хмару,
- поштою собі.

## Крок 2. Дозволити встановлення

Це не гра з Google Play, тож Android спитає дозволу. Це нормально й безпечно
для застосунку, встановленого напряму.

Відкрий файл `РозкладкаВ.apk` (через "Файли"/"Провідник" на телефоні) →
з'явиться попередження — натисни **"Все ж встановити"** (або **"Параметри"
→ дозволити встановлення з цього джерела**, якщо попросить окремо).

## Крок 3. Встановити

Натисни **"Встановити"** → після завершення **"Відкрити"**.

Готово — застосунок на головному екрані, як і будь-який інший.

---

**Якщо Android каже "Заблоковано Play Protect" або схоже:**
Натисни **"Детальніше"** → **"Встановити все одно"**. Це стандартне
попередження для будь-якого застосунку не з Google Play, не залежить від
конкретного застосунку.

**Якщо Android каже "Застосунок не встановлено" / щось про несумісність
версій:** на телефоні вже стоїть стара версія, підписана інакше (до
версії 2.8) — новий APK не може її "оновити". Це одноразова ситуація.
1. Якщо в застосунку вже є важливі дані — спочатку відкрий його, зайди в
   "Статистика" (іконка 📊) і натисни "Поділитися" (експорт CSV) — збережи
   файл собі (Google Диск, Telegram тощо).
2. Видали стару версію: Налаштування телефону → Застосунки → РозкладкаВ →
   Видалити.
3. Встанови новий APK як зазвичай (кроки вище).
4. Якщо експортував дані — постав файл назад через "Статистика" →
   іконка 📥 (імпорт CSV) — усе повернеться.

Після цього одноразового кроку подальші оновлення підуть звичайним
способом (просто новий APK поверх старого), без видалення.

**Оновлення на нову версію (звичайний випадок):** просто встанови новий
APK так само — старі дані (управління, будівлі, вогнегасники) залишаються.
