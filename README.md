# РозкладкаВ

Мобільний застосунок (Android) для розрахунку норм протипожежного оснащення
та обліку фактичної наявності вогнегасників: скільки вогнегасної речовини,
вогнегасників і пожежних щитів має бути в будівлях та на території, виходячи
з площ приміщень — і чого саме бракує в реальному інвентарі.

**Логіка розрахунку норми** (див. `lib/services/calculation_service.dart`):
- Звичайні приміщення: 1 л вогнегасної речовини на кожні 10 м² (по кожному
  поверху сумарно, за вирахуванням площі кабінетів з комп'ютерною технікою).
- Кабінети з комп'ютерною технікою: окремий вогнегасник по кожному кабінету —
  до 20 м² один клас, понад 20 м² більший клас.
- Територія (ТВУЗ): 1 пожежний щит на кожні 5000 м².

⚠️ Точні класи/маси вогнегасників у коді позначені `TODO` — зафіксовані зі
слів замовника, без звірки з конкретним пунктом наказу.

**Облік реальних вогнегасників:**
- Кожен вогнегасник у системі має ідентифікатор (порядковий номер,
  присвоюється автоматично), заводський номер, інвентарний номер (лише
  цифри, мінімум 4 — перші 4 це код субрахунку бухобліку), тип і модель.
- Чотири типи, кожен зі своєю номенклатурою моделей (див.
  `lib/models/extinguisher_model_catalog.dart`):
  - **ВП** (порошковий) — ВП-1…ВП-12 (переносні), ВП-20…ВП-100 (пересувні), кг
  - **ВВК** (вуглекислотний) — ВВК-1.4…ВВК-7 (переносні), ВВК-10…ВВК-55
    (пересувні), кг
  - **ВВП** (водопінний) — ВВП-2…ВВП-9 (переносні), ВВП-25…ВВП-100
    (пересувні), л
  - **ВВ** (водний) — ВВ-5…ВВ-10 (переносні), ВВ-50…ВВ-100 (пересувні), л
- Кабінети з комп'ютерною технікою обслуговуються виключно вогнегасниками
  ВВК — фіксоване правило.
- Для звичайних приміщень дозволені типи налаштовуються (Налаштування →
  за замовчуванням лише ВП).
- Усе керування вогнегасниками (перегляд, додавання, редагування) — на
  головному екрані.
- Застосунок рахує **недостачу**: скільки ще потрібно долучити вогнегасників
  певного типу/моделі, порівнюючи норму з фактично зареєстрованими
  одиницями (зведений звіт).
